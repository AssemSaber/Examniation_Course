# Examniation_Course
### Built a role-based online examination system in Java for managing courses, exams, and student performance.
**- Designed and implemented functionalities for Admin, Lecturer, and Student roles to ensure proper access control and workflow.**
<br>
<br>
**- Admins can create courses and assign them to specific lecturers**
<br>
<br>
**- Lecturers can create online exams with correct answers and time limits, manage questions (create, update, delete), update exam time, view all student grades, and search by student ID.**
<br>
<br>
**-Students can browse and register for multiple courses, take exams, and receive instant grades upon submission.**
<br>
